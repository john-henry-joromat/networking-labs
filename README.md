# Networking Labs

Welcome to my practical networking laboratory!

This repository documents my hands-on networking projects using Cisco Packet Tracer, focusing on networking fundamentals, switching, routing, IPv4 addressing, and network troubleshooting.

## Learning Objectives

- Understand IPv4 addressing and subnetting.
- Configure and troubleshoot Cisco switches and routers.
- Understand VLANs and trunking.
- Implement inter-VLAN routing.
- Practice DHCP and static routing.
- Develop practical network troubleshooting skills.
